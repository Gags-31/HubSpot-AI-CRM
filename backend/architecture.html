01 · Conversational CRM Application frontend/, app/routers/

The dealer or consumer talks; every button maps to an API action that the agent layer handles.

flowchart TD U[Consumer / Dealer] --> UI[Conversational UI] UI --> B1[Start / End Conversation] UI --> B2[Generate Proposal] UI --> B3[View Customer] UI --> B4[Ask AI] UI --> B5[Approve / Send] UI --> B6[Follow Up] B1 --> API[FastAPI Routers] B2 --> API B3 --> API B4 --> API B5 --> API B6 --> API

02 · Consumer-Specific Digital Workspace app/routers/workspace.py

Every consumer gets an auto-created digital workspace with 8 standard sections.

flowchart LR C[New consumer detected] --> W[Create Consumer_00X workspace] W --> P[Profile] W --> CV[Conversations] W --> R[Requirements] W --> PR[Products] W --> PO[Proposals] W --> D[Documents] W --> F[Followups] W --> H[Interaction_History] CV --> P R --> PR PR --> PO PO --> F F --> H

03 · Conversation Recording System app/services/stt.py, app/routers/conversations.py

Voice is transcribed with open-source Whisper; every exchange is timestamped and stored.

flowchart TD V[Voice conversation] --> W[Whisper speech-to-text] T[Text conversation] --> ST[(Conversation store)] W --> ST ST --> M[Metadata: timestamp, participants] M --> SUM[Summary] M --> ENT[Extracted entities] ENT --> REQ[Requirements] ENT --> AGR[Agreements] ENT --> SEN[Sentiment] ENT --> TOP[Topics] ENT --> ACT[Action items]

04 · NLP Conversation Intelligence app/services/nlp.py

Conversations are not just stored, they are understood.

flowchart TD IN[Conversation text] --> NER[Named Entity Recognition] IN --> ID[Intent Detection] IN --> SA[Sentiment Analysis] IN --> RE[Requirement Extraction] IN --> PI[Product Identification] IN --> PE[Price / Quantity / Date Extraction] IN --> AD[Agreement Detection] IN --> TC[Topic Classification] IN --> SU[Summarization] IN --> CD[Complaint Detection] IN --> SS[Semantic Similarity] RE --> OUT[Structured requirement set] AD --> OUT SU --> OUT
